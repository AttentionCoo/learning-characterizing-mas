# 多智能体个性化学习系统 — 接口文档

> 基于现有 MedLLM / MultiAgentNeuroSystem 架构魔改，将医疗场景迁移至高等教育个性化学习场景。
> 保留原有三层架构（Vue3 前端 → Java Spring Boot 后端 → Python FastAPI 模型层）、JWT 认证、SSE 流式推送、统一 Result 响应体等核心设计。

---

## 1. 全局约定

### 1.1 Base URL

| 环境 | 后端 Base URL | 模型层 Base URL |
|------|--------------|----------------|
| 开发 | `http://localhost:8080/api` | `http://localhost:8000` |
| 生产 | `https://{domain}/api` | `https://{domain}/model` |

### 1.2 统一响应体 `Result`

所有非流式接口统一返回以下 JSON 结构（与原项目保持一致）：

```json
{
  "code": 1,        // 1=成功, 0=失败
  "msg": "success", // 描述信息
  "data": {}        // 业务数据，失败时可能为 null
}
```

### 1.3 认证方式

除 `/api/user/login` 和 `/api/user/register` 外，所有接口均需携带 JWT Token：

```
Authorization: Bearer <token>
token: <token>
```

后端通过 `Tokeninterceptor` + `ThreadLocalUtil` 解析用户身份，模型层通过 `verify_token()` 校验。

### 1.4 SSE 流式事件格式

流式接口（对话画像构建、资源生成、智能辅导）采用 SSE（Server-Sent Events）协议，事件格式与原项目一致：

```
event: <事件类型>
id: <talkId>:<seq>    // 仅业务事件携带，用于断线续传
data: <JSON字符串>
```

**标准事件类型**：

| 事件类型 | 说明 | data 结构 |
|---------|------|----------|
| `init` | 连接建立，返回会话ID | `{"type":"init","talkId":"123","newTalk":true}` |
| `node_start` | 智能体节点开始推理 | `{"type":"node_start","node":"profiler","label":"正在分析学习特征..."}` |
| `token` | 内容片段（增量） | `{"type":"token","content":"..."}` |
| `thinking` | 思考过程展示 | `{"type":"thinking","step":1,"title":"知识基础分析","content":"..."}` |
| `done` | 流式结束 | `{"type":"done","talkId":"123","title":"学习画像构建"}` |
| `error` | 错误 | `{"type":"error","code":"E2001","message":"..."}` |
| `resume` | 断线续传恢复 | `{"type":"resume","talkId":"123","content":"..."}` |

**心跳与关闭**：每 15 秒发送 `: heartbeat` comment，流结束后发送 `: close` comment。

### 1.5 分页参数约定

所有分页接口统一使用以下查询参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | 1 | 当前页码（从1开始） |
| `size` | int | 10 | 每页条数 |

分页响应结构：

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "total": 100,
    "records": [...]
  }
}
```

## 3. 对话式学习画像模块

> 核心功能1：通过自然语言对话自动抽取特征，构建动态学生画像，支持画像的随学随新。
> 画像包含不少于6个维度：知识基础、认知风格、学习目标、易错点偏好、学习节奏、资源偏好等。

### 3.1 对话式画像构建（SSE 流式）

**POST** `/api/profile/conversation`

> Content-Type: `application/json`
> Response Content-Type: `text/event-stream`

通过自然语言对话，AI 自动抽取学生特征并构建/更新学习画像。采用 SSE 流式返回，前端可实时展示 AI 思考过程与画像维度分析。

请求体：

```json
{
  "talkId": "string|null",     // 对话ID，首次传 null 或不传，续聊传已有 talkId
  "message": "string",         // 学生输入的自然语言内容
  "images": ["string"]         // 可选，上传图片的 Base64 列表（如成绩单截图），最多3张
}
```

SSE 事件流示例：

```
event: init
data: {"type":"init","talkId":"1001","newTalk":true}

event: node_start
data: {"type":"node_start","node":"profiler","label":"正在分析学习特征..."}

event: thinking
data: {"type":"thinking","step":1,"title":"知识基础分析","content":"正在从对话中提取学生已掌握的知识点..."}

event: token
data: {"type":"token","content":"根据你的描述，"}

event: token
data: {"type":"token","content":"我为你构建了以下学习画像..."}

event: node_start
data: {"type":"node_start","node":"dimension_builder","label":"正在更新画像维度..."}

event: token
data: {"type":"token","content":"你的知识基础维度已更新为：已掌握Python基础语法..."}

event: done
data: {"type":"done","talkId":"1001","title":"学习画像构建"}
```

**多智能体协作说明**：

| 智能体角色 | 节点名 | 职责 |
|-----------|--------|------|
| 画像对话智能体 (Profiler Agent) | `profiler` | 与学生自然对话，引导表达学习背景与需求 |
| 特征抽取智能体 (Extractor Agent) | `extractor` | 从对话内容中抽取结构化特征（专业、目标、知识水平等） |
| 画像构建智能体 (Portrait Builder Agent) | `dimension_builder` | 将抽取的特征映射到6+维度，生成/更新动态画像 |

## 4. 多智能体协同资源生成模块

> 核心功能2：不同角色智能体协作完成至少5种类型的个性化资源生成。
> 资源类型：专业课程讲解文档、知识点思维导图、不同类型练习题目、拓展阅读材料、多模态教学视频/动画、代码类实操案例。

### 4.1 综合资源生成（SSE 流式）

**POST** `/api/resources/generate`

> 核心接口：根据学生画像和学习需求，多智能体协同生成多种类型学习资源。
> Content-Type: `application/json`
> Response Content-Type: `text/event-stream`

请求体：

```json
{
  "talkId": "string|null",           // 对话ID，首次为 null
  "message": "string",               // 学习需求描述，如"帮我生成机器学习基础的学习资料"
  "resourceTypes": [                 // 需要生成的资源类型，至少选1种
    "document",                      // 课程讲解文档
    "mindmap",                       // 知识点思维导图
    "quiz",                          // 练习题目
    "reading",                       // 拓展阅读材料
    "video_script",                  // 教学视频/动画脚本
    "code_practice"                  // 代码实操案例
  ],
  "courseName": "人工智能导论",       // 课程名称
  "knowledgePoints": [               // 知识点列表
    "线性回归",
    "梯度下降",
    "损失函数"
  ],
  "difficulty": "intermediate",      // 难度：beginner/intermediate/advanced
  "images": ["string"]               // 可选，参考图片 Base64
}
```

SSE 事件流示例：

```
event: init
data: {"type":"init","talkId":"2001","newTalk":true}

event: node_start
data: {"type":"node_start","node":"requirement_analyzer","label":"正在分析学习需求..."}

event: thinking
data: {"type":"thinking","step":1,"title":"需求分析","content":"正在结合学生画像分析资源需求..."}

event: node_start
data: {"type":"node_start","node":"document_writer","label":"正在生成课程讲解文档..."}

event: token
data: {"type":"token","content":"# 线性回归详解\n\n## 1. 基本概念\n..."}

event: node_start
data: {"type":"node_start","node":"mindmap_generator","label":"正在生成思维导图..."}

event: token
data: {"type":"token","content":"```mermaid\nmindmap\n  root((线性回归))\n..."}

event: node_start
data: {"type":"node_start","node":"quiz_creator","label":"正在生成练习题目..."}

event: token
data: {"type":"token","content":"## 练习题\n\n### 选择题\n1. 线性回归的损失函数通常是？\n..."}

event: done
data: {"type":"done","talkId":"2001","title":"资源生成完成","resourceIds":[301,302,303]}
```

**多智能体协作矩阵**：

| 智能体角色 | 节点名 | 职责 | 生成资源类型 |
|-----------|--------|------|------------|
| 需求分析智能体 (Requirement Analyzer) | `requirement_analyzer` | 结合画像分析需求，拆解生成任务 | — |
| 文档撰写智能体 (Document Writer) | `document_writer` | 生成专业课程讲解文档 | `document` |
| 思维导图智能体 (Mindmap Generator) | `mindmap_generator` | 生成知识点思维导图（Mermaid/JSON） | `mindmap` |
| 题目生成智能体 (Quiz Creator) | `quiz_creator` | 生成多类型练习题目 | `quiz` |
| 阅读推荐智能体 (Reading Curator) | `reading_curator` | 生成拓展阅读材料与推荐 | `reading` |
| 视频脚本智能体 (Video Script Writer) | `video_script_writer` | 生成教学视频/动画脚本 | `video_script` |
| 代码实操智能体 (Code Practice Agent) | `code_practice` | 生成代码实操案例与项目 | `code_practice` |
| 质量审核智能体 (Quality Reviewer) | `quality_reviewer` | 审核资源质量与个性化匹配度 | — |

### 6.1 智能辅导问答（SSE 流式）

**POST** `/api/tutor/ask`

> Content-Type: `application/json`
> Response Content-Type: `text/event-stream`

请求体：

```json
{
  "talkId": "string|null",          // 对话ID，首次为 null
  "question": "为什么梯度下降可能会陷入局部最优？",  // 学生问题

    "currentKnowledgePoint": "梯度下降",
    "pathId": 501,
    "stepId": 2
  },
  "preferredAnswerFormat": ["text", "diagram", "code"],  // 期望的回答形式
  "images": ["string"]              // 可选，问题相关图片
}
```

SSE 事件流示例：

```
event: init
data: {"type":"init","talkId":"3001","newTalk":true}

event: node_start
data: {"type":"node_start","node":"question_analyzer","label":"正在分析问题..."}

event: thinking
data: {"type":"thinking","step":1,"title":"问题理解","content":"学生询问梯度下降的局部最优问题..."}

event: node_start
data: {"type":"node_start","node":"text_tutor","label":"正在生成文字解答..."}

event: token
data: {"type":"token","content":"梯度下降陷入局部最优的原因是..."}

event: node_start
data: {"type":"node_start","node":"diagram_generator","label":"正在生成图解说明..."}

event: token
data: {"type":"token","content":"```mermaid\ngraph TD\n    A[起点] --> B{局部最优?}\n..."}

event: node_start
data: {"type":"node_start","node":"code_tutor","label":"正在生成代码示例..."}

event: token
data: {"type":"token","content":"```python\nimport numpy as np\n# 模拟梯度下降陷入局部最优\n..."}

event: done
data: {"type":"done","talkId":"3001","title":"梯度下降答疑"}
```

**多智能体协作说明**：

| 智能体角色 | 节点名 | 职责 |
|-----------|--------|------|
| 问题分析智能体 (Question Analyzer) | `question_analyzer` | 理解学生问题，识别知识盲区 |
| 文字辅导智能体 (Text Tutor) | `text_tutor` | 生成详细文字解答 |
| 图解生成智能体 (Diagram Generator) | `diagram_generator` | 生成图解/Mermaid图说明 |
| 代码辅导智能体 (Code Tutor) | `code_tutor` | 生成代码示例与解释 |
| 视频讲解智能体 (Video Explainer) | `video_explainer` | 生成短视频讲解脚本 |

## 11. 数据库表设计（新增/改造）

> 在原 `medai` 数据库基础上新增以下表，原有 `login_register_info`、`talk`、`cont` 等表保留复用。

### 11.1 student_profile（学生画像表）

```sql
CREATE TABLE IF NOT EXISTS student_profile (
    id              BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT UNSIGNED NOT NULL UNIQUE COMMENT '关联用户ID',
    dimensions      JSON            NOT NULL COMMENT '画像维度数据（6+维度JSON）',
    raw_summary     TEXT                     COMMENT '对话摘要文本',
    version         INT             NOT NULL DEFAULT 1 COMMENT '画像版本号，每次更新+1',
    create_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id(user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学生画像表';
```

### 11.2 learning_resource（学习资源表）

```sql
CREATE TABLE IF NOT EXISTS learning_resource (
    id                BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY,
    user_id           BIGINT UNSIGNED NOT NULL COMMENT '生成该资源的用户ID',
    title             VARCHAR(256)    NOT NULL COMMENT '资源标题',
    type              VARCHAR(32)     NOT NULL COMMENT '资源类型：document/mindmap/quiz/reading/video_script/code_practice',

    knowledge_points  JSON                     COMMENT '关联知识点列表',
    difficulty        VARCHAR(16)              COMMENT '难度：beginner/intermediate/advanced',
    content           LONGTEXT                 COMMENT '资源内容（文本/JSON/Mermaid等）',
    file_url          VARCHAR(512)             COMMENT 'OSS文件链接',
    metadata          JSON                     COMMENT '元数据（字数、阅读时长、生成链路等）',
    talk_id           BIGINT UNSIGNED          COMMENT '关联的对话ID',
    create_time       DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time       DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_user_id(user_id),
    INDEX idx_type(type),
    INDEX idx_course(course_name)

```

## 12. 错误码定义

| 错误码 | HTTP状态码 | 说明 |
|--------|-----------|------|
| E1001 | 401 | Token 无效或已过期 |
| E1002 | 403 | 无权限访问 |
| E1003 | 429 | 请求频率超限 |
| E2001 | 400 | 请求参数错误 |
| E2002 | 404 | 资源不存在 |
| E2003 | 410 | SSE 会话缓存已过期，无法断线续传 |
| E2004 | 400 | Last-Event-ID 与请求 talkId 不匹配 |
| E3001 | 503 | 模型服务未就绪 |
| E3002 | 500 | 模型推理失败 |
| E3003 | 504 | 模型推理超时 |
| E4001 | 400 | 画像维度数据格式错误 |
| E4002 | 400 | 资源类型不支持 |
| E4003 | 400 | 学习路径步骤顺序冲突 |
| E4004 | 400 | 测验答案格式错误 |
