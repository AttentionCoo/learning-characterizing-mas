## 一、作品概述

### 1.1 作品简介

LearnAgent 是一个面向高等教育场景（以脑卒中方向医学教育为示范领域）的个性化学习智能体系统。系统以高校专业课程知识库为底座，融合 **多智能体协同推理**、**Hybrid RAG 证据前置检索**、**共享记忆系统**、**多模态医学影像分析** 与 **全栈响应式流式架构**，实现从学生画像构建到个性化资源生成、智能辅导答疑、学习路径规划、学习效果评估的完整教学闭环。

系统采用 **三层解耦架构**：前端交互层（Vue 3.5）、后端服务层（Java 21 + Spring Boot 3.3）、模型推理层（Python 3.11 + FastAPI + LangGraph），通过 WebClient/WebFlux 实现全链路响应式流式管道，AI 思考过程对用户完全透明可视化。

### 2.2 全链路流式数据管道

系统的核心创新之一是实现了从前端到模型层的**全链路响应式流式管道**，使得 AI 推理的每一步思考过程对用户完全透明：

```
 学生输入                                                    前端渲染
    │                                                          ▲
    ▼                                                          │
┌─────────┐  WebClient   ┌─────────┐  AsyncTaskManager  ┌──────────┐
│  Java   │ ──────────►  │ FastAPI │ ─────────────────► │ Learning │
│ 鉴权限流 │   异步调用     │  接收    │    创建任务         │  Agent   │
└─────────┘              └─────────┘                    └──────────┘
                                                              │
                         ┌────────────────────────────────────┘
                         ▼
              LangGraph astream_events
                         │
                         ▼
              _translate_event 翻译标准事件
                         │
                         ▼
              asyncio.Queue ──► Java Flux 转发 ──► Vue3 ReadableStream
```

**关键技术点**：
- **Java WebFlux**：基于 Project Reactor 的非阻塞 I/O，WebClient 异步调用 Python 模型服务
- **LangGraph astream_events**：Python 端以异步生成器逐块输出推理事件
- **asyncio.Queue**：Python 端异步队列缓冲，确保事件有序传递
- **Flux 转发**：Java 端将上游流式数据零拷贝转发至前端 SSE
- **Vue3 ReadableStream**：前端逐块消费流式数据，驱动 Markdown 增量渲染

### 2.3 Hybrid RAG 检索架构（三阶漏斗）

作为系统的知识底座，Hybrid RAG 采用三阶漏斗检索策略，确保检索结果的准确性与相关性：

```
                         用户查询
                            │
                            ▼
            ┌───────────────────────────────┐
            │     第一阶：宽召回              │
            │  ┌──────────┐  ┌──────────┐   │
            │  │ 向量检索   │  │  BM25    │   │
            │  │ (语义相似) │  │ (关键词)  │   │
            │  │ top-20    │  │ top-20   │   │
            │  └──────────┘  └──────────┘   │
            │        最多 40 篇候选            │
            └───────────────┬───────────────┘
                            │
                            ▼
            ┌───────────────────────────────┐
            │     第二阶：RRF 粗排            │
            │  倒数排名融合                    │
            │  RRF(d) = 1/(60+Rankᵥ)        │
            │         + 1/(60+Rank_b)       │
            │  40 篇 → 20 篇候选              │
            └───────────────┬───────────────┘
                            │
                            ▼
            ┌───────────────────────────────┐
            │     第三阶：Reranker 精排       │
            │  4 模型自动切换容灾：            │
            │  xf-xinghuo-rerank-v1          │
            │    → gte-rerank-v2            │
            │    → xf-xinghuo-rerank         │
            │    → gte-rerank               │
            │  20 篇 → 3 篇最终结果           │
            └───────────────────────────────┘
```

| 阶段 | 技术 | 输入 → 输出 | 创新点 |
|:---|:---|:---|:---|
| **宽召回** | 向量检索 (DashScope Embedding) + BM25 关键词检索 | 各 20 篇 → 最多 40 篇 | 双路并行召回，语义与关键词互补覆盖 |
| **粗排** | RRF 倒数排名融合 | 40 篇 → 20 篇 | 零成本零延迟，分离 Dense/Sparse 分值区间 |
| **精排** | BGEReranker (DashScope ReRank API) | 20 篇 → 3 篇 | 4 模型自动切换容灾，降级时原始结果兜底 |

**检索优化**：
- **检索缓存**：MD5(query+top_k) 哈希，TTL 300 秒，避免重复查询
- **内容去重**：基于 page_content 内容去重，同一内容取最高排名
- **QA 扩充**：QAGenerator (xf-xinghuo-turbo) 自动生成 QA 对扩充向量库，增强语义覆盖
- **文档分块**：RecursiveCharacterTextSplitter (chunk_size=512, overlap=128)，平衡语义完整性与检索粒度

## 三、核心功能模块

### 3.1 对话式学习画像自主构建

> **赛题要求**：必选功能 1 — 构建学生画像，维度不少于 6 个

系统通过自然语言对话引导学生描述学习背景，画像对话智能体与特征抽取智能体协同工作，从对话中自动提取结构化特征，构建 **8 维度动态画像**：

| 维度 | 说明 | 示例 |
|:---|:---|:---|
| **知识基础** | 学生在目标领域的已有知识水平 | 初级/中级/高级 |
| **认知风格** | 学生偏好的信息处理方式 | 视觉型/听觉型/实践型 |
| **学习目标** | 短期与长期学习目标 | 通过期末考试/掌握脑血管疾病诊断 |
| **易错模式** | 学生常见错误类型 | 概念混淆/细节遗漏/逻辑跳跃 |
| **学习节奏** | 学生偏好的学习速度 | 快速/适中/稳健 |
| **资源偏好** | 偏好的学习资源类型 | 视频/文字/实操/思维导图 |
| **临床经验** | 临床实践经验水平 | 无经验/见习/实习 |
| **情绪状态** | 当前学习情绪 | 积极/中性/焦虑/倦怠 |

**核心特性**：
- 画像随学随新：每次对话后自动更新画像维度，版本号自增追溯
- 多轮对话上下文摘要：长对话场景下自动压缩历史，确保上下文连贯
- 手动编辑：用户可对 AI 生成的画像维度进行修正

### 3.2 多智能体协同资源生成

> **赛题要求**：必选功能 2 — 个性化资源生成，不少于 5 种类型

系统定义 **9 个专家智能体**，基于 LangGraph StateGraph 进行有向图编排，YAML 配置驱动，支持动态编排与辩论-仲裁机制：

| 智能体 | 优先级 | 职责 |
|:---|:---:|:---|
| 画像对话智能体 | 1 | 引导式对话，收集学生信息 |
| 特征抽取智能体 | 2 | 自动抽取 8 维度画像特征 |
| 需求分析智能体 | 3 | 分析需求，拆解任务 |
| 医学影像分析智能体 | 3.5 | 基于影像结构化发现提供影像-临床关联分析 |
| 文档撰写智能体 | 4 | 生成专业课程讲解文档 |
| 题目生成智能体 | 5 | 生成多类型练习题目 |
| 质量审核智能体 | 6 | 审核学术准确性与个性化匹配度 |
| 学习激励智能体 | 7 | 情绪识别与激励反馈 |
| 仲裁智能体 | 8 | 依据证据链裁决辩论（难度 ≥ 0.6 时加入） |

**生成的 7 类资源**：

| 资源类型 | 说明 | 生成策略 |
|:---|:---|:---|
| 课程讲解文档 (document) | 结构化系统讲解 | 知识体系 + 案例 + 思考题 |
| 思维导图 (mindmap) | 知识体系可视化 | 层级结构 + 关联标注 |
| 练习题目 (quiz) | 多题型自测 | 单选/多选/判断/简答 |
| 拓展阅读 (reading) | 临床指南与文献 | 证据等级标注 + 溯源 |
| 视频脚本 (video_script) | 教学视频脚本 | 分镜描述 + 讲解词 |
| 代码实操 (code_practice) | 医学编程实践 | 数据集 + 分析任务 |
| 综合批量生成 | 多资源协同 | 一次请求生成多类型 |

**辩论-仲裁机制**：不同智能体就争议知识点提出对立观点，经多轮辩论后由仲裁智能体依据证据链裁决，减少单一模型偏见。

**动态退火策略**：质量校验失败时自动分类驳回原因（5 类），生成针对性修正指引，衰减不通过智能体的发言权重（0.7 因子，最低 0.2），最大反思 3 次。

**动态编排**：根据意图类型和难度评分动态裁剪参与智能体数量（3-7 位 + 仲裁），避免资源浪费。

### 3.3 学习路径规划

> **赛题要求**：加分项 1 — 提供学习路径建议

系统根据学生画像自动生成 **5-15 步**个性化学习路径，每步包含：

- 主题描述与学习目标
- 关联知识点标签
- 精准资源推荐（从资源库匹配）
- 前置步骤依赖关系
- 预计学习时长

支持路径动态调整，当学生完成某步骤或评估结果变化时自动更新后续路径。

### 3.4 智能辅导

> **赛题要求**：加分项 2 — 多轮对话辅导

系统提供即时多模态答疑辅导，核心特性：

- **多轮上下文感知**：自动关联历史对话，支持连续追问
- **多模态输入**：支持文字 + 图片（xf-xinghuo-vl-max 视觉理解）
- **流式思考透明**：AI 推理的每一步思考过程实时展示
- **偏好回答形式**：支持简洁/详细/教学级三种回答风格

### 3.5 学习效果评估

> **赛题要求**：加分项 3 — 学习效果评估

系统从 **5 个维度**量化评估学生学习效果：

| 维度 | 说明 | 权重 |
|:---|:---|:---|
| 知识掌握度 | 对知识点的理解和记忆程度 | 30% |
| 学习效率 | 单位时间内的学习产出 | 20% |
| 技能应用 | 将知识应用于实践的能力 | 20% |
| 学习一致性 | 学习行为与目标的匹配度 | 15% |
| 进度对齐度 | 与路径规划的同步程度 | 15% |

评估结果以 **雷达图 + 热力图 + 文字报告** 形式呈现，并自动触发学习路径优化建议。

### 3.6 代码辅助

> **赛题要求**：加分项 4 — 代码辅助开发

系统支持 Python 代码在线执行与 AI 编程辅助：

- **代码生成**：根据自然语言描述生成 Python 代码
- **在线执行**：沙箱环境运行，支持超时控制（默认 30 秒）
- **错误诊断**：自动捕获运行时错误并给出修复建议
- **实操案例**：面向医学数据处理的编程实操案例

### 3.7 医学多模态影像分析

> **赛题要求**：加分项 5 — 多模态能力

系统基于 xf-xinghuo-vl-max 多模态大模型，实现 10 类医学影像的自动识别与结构化分析：

| 影像类型 | 标识 | 分析策略 |
|:---|:---|:---|
| 神经影像 CT | `neuroimaging_ct` | 脑实质密度评估 · 出血/缺血征象识别 |
| 神经影像 MRI | `neuroimaging_mri` | DWI/ADC 序列解读 · 梗死核心/半暗带评估 |
| DSA 血管造影 | `angiography_dsa` | 血管狭窄/闭塞评估 · 侧支循环分级 |
| 病理切片 | `pathology` | 细胞形态学分析 · 病理分期辅助 |
| 心电图 | `ecg` | 心率/心律分析 · ST-T 改变识别 |
| 临床照片 | `clinical_photo` | 神经系统体征 · 皮肤病变 |
| 检验报告 | `lab_report` | 血常规/生化/凝血功能指标提取 |
| 影像报告 | `radiology_report` | 报告文本结构化提取 |
| 医学图解 | `medical_illustration` | 解剖结构标注 · 病理机制图解 |
| 课件资料 | `courseware` | 教学内容提取 · 知识点归纳 |

**核心创新**：

- **多图对比分析**：同模态不同时间点对比（治疗前后 CT）或不同模态交叉对比（CT vs MRI），自动生成对比报告
- **DICOM 元数据提取**：提取扫描参数和序列信息，不提取患者隐私
- **检验报告 OCR**：自动提取检验指标名称、数值、参考范围、异常标记
- **处方 OCR**：解析药品名称、剂量、用法、频次等结构化信息
- **Vision-RAG 桥接**：影像分析发现自动桥接本地知识库循证检索

## 四、技术创新点

### 4.1 共享记忆系统

多智能体间通过共享记忆系统实现跨会话知识保留与冲突消解，三层架构：

| 层次 | 核心类 | 说明 |
|:---|:---|:---|
| **物理层** | `SharedMemoryStore` | ChromaDB 向量存储，语义级检索，三级降级容错 |
| **逻辑层** | `ConsensusEngine` + `AgentReputationStore` | 信誉加权投票共识，跨会话信誉持久化 |
| **元记忆过滤** | `MetaMemoryFilter` | 四维熵值评分（Shannon 熵 · 关键词密度 · Token 密度 · 长度），低熵高价值信息才持久化 |

数据流闭环：`retrieve_node` 读取共享记忆 → `reason_node` 共识投票 + 熵值过滤写入 → `validate_node` 信誉反馈更新。

### 4.2 证据前置 Hybrid RAG

区别传统 RAG "先推理后检索"的模式，系统采用"先检索后推理"的证据前置策略：

- 检索结果以结构化证据形式注入推理上下文
- 强制文献溯源，每条结论标注来源
- 三阶漏斗 + 4 模型容灾，保障检索质量

### 4.3 防幻觉与质量保障

双层校验机制对抗大模型幻觉：

1. **规则引擎层**：格式校验、关键词检测、来源一致性检查
2. **LLM 反思层**：质量审核智能体深度审查学术准确性

校验失败触发动态退火修正，最多 3 轮反思，确保输出质量。

### 4.4 全栈响应式流式管道

创新的端到端流式架构：

- Java WebFlux 非阻塞 I/O + Python Asyncio 深度流式融合
- AI 思考过程完全透明可视化（Thinking Panel）
- SSE 断线续传：滑动窗口缓存 + Last-Event-ID 机制，5 分钟内续传成功率 100%

### 4.5 企业级鉴权与限流体系

- **双重拦截器**：RefreshTokenInterceptor（自动续期）+ TokenInterceptor（权限校验）
- **单设备登录**：JTI 机制确保新设备登录时旧设备 Token 自动失效
- **Redisson 分布式限流**：RSemaphore 全局并发量控制（permits=20），AI 服务过载保护
- **异步持久化**：对话记录入库与 AI 回复流分离，不阻塞流式响应

### 4.6 学习风险评估

集成阿里云百炼平台，通过 `LearningRiskAnalyzer` 异步评估学生学习风险：

- 低风险 / 中风险 / 高风险 三级判定
- 针对性学习改进建议（50 字以内）
- 学习状况综合评估摘要（50 字以内）
- 基于 asyncio 异步调用，不阻塞主流程

系统的核心优势在于：

1. **三群协同多智能体架构**：9 个专家智能体分工明确，辩论-仲裁 + 动态退火保障输出质量
2. **证据前置 Hybrid RAG**：三阶漏斗检索，确保知识来源可靠、可追溯
3. **全栈响应式流式管道**：AI 思考过程完全透明，SSE 断线续传保障体验
4. **共享记忆系统**：跨会话知识保留，信任加权投票共识，四维信息熵过滤
5. **多模态能力**：10 类医学影像分析 + OCR + Vision-RAG 桥接循证检索
6. **企业级工程质量**：71 条自动化测试用例，并发性能验证，容灾降级保障

本作品完整覆盖赛题 A3 的全部必选功能与加分项，功能实现度 100%，测试覆盖率 100%，具备实际部署运行能力。
