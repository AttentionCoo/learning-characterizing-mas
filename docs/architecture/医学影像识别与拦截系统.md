# 医学影像识别与拦截系统

> 本文档描述 LearnAgent 系统中医学多模态影像的识别、分析与拦截机制。

---

## 1. 系统架构概览

```
用户上传图片
    │
    ▼
┌────────────────────────────────────────────────────────────┐
│                     intent_node (意图识别)                  │
│  有图片时放宽文本关键词预检，标记 _image_pending_check      │
│  交由 vision_node 做最终判断                               │
└────────────────────────────────────────────────────────────┘
    │
    ▼
┌────────────────────────────────────────────────────────────┐
│                   vision_node (影像分析 + 拦截)             │
│                                                            │
│  Tier 1 ─ 中文门控 Prompt → VL 模型直接判断是否脑卒中相关   │
│  Tier 2 ─ 影像类型检测 → CT/MRI/DSA 直接放行               │
│  Tier 3 ─ 医学术语密度计数 → 核心硬指标防线                 │
└────────────────────────────────────────────────────────────┘
    │
    ├── 放行 ──→ retrieve → reason → validate → report
    │
    └── 拦截 ──→ reject_image_node → 友好拒绝提示
```

---

## 2. 三层防护机制详解

### 2.1 Tier 1：中文门控（快速拦截）

**目的**：在昂贵的结构化分析之前，用一次轻量 VL 调用来快速判断。

**Prompt**（中文版，`_STROKE_GATE_PROMPT_CN`）：

```
你是脑卒中（中风）医学教育系统的严格守门人。请仔细查看这张图片，
然后只回答一个字："是" 或 "否"。

图片属于以下任一类型，回答"是"：
- 脑部CT、脑部MRI、脑血管造影（CTA/MRA/DSA）
- 头部/颅脑的医学扫描影像
- 脑血管相关的病理切片
- 脑卒中体征的临床照片（面瘫、肢体偏瘫等）
- 脑卒中相关的检验报告单
- 脑卒中相关的影像诊断报告
- 脑卒中相关的心电图（房颤等）
- 脑血管解剖或卒中机制的医学图解

图片属于以下任一类型，回答"否"：
- 普通人像照片（自拍、大头照、证件照、合影等）
- 文字资料（数学题、试卷、作业、笔记、课本、PPT等）
- 日常场景（动物、食物、建筑、风景、物品等）
- 手机/电脑截图、社交媒体、聊天记录
- 非脑部的医学影像（胸部X光、骨折、皮肤、牙科等）
```

**调用方式**：流式调用 Qwen-VL-Max，逐张检查，任一通过即放行。

**容错**：API 异常时默认放行（交由 Tier 2/3 处理）。

---

### 2.2 Tier 2：影像类型检测

**目的**：已知的脑卒中影像类型直接放行，无需额外检测。

**直接放行的类型**（`_STROKE_RELATED_IMAGE_TYPES`）：

| 类型 | 说明 |
|------|------|
| `neuroimaging_ct` | 头部CT |
| `neuroimaging_mri` | 头部MRI |
| `neuroimaging_angiography` | 脑血管造影（CTA/MRA/DSA） |

**需要进一步检测的类型**（`_POTENTIALLY_STROKE_RELATED_TYPES`）：

| 类型 | 说明 |
|------|------|
| `pathology_slide` | 病理切片 |
| `clinical_photo` | 临床照片 |
| `lab_report` | 检验报告 |
| `radiology_report` | 影像报告 |
| `ecg_waveform` | 心电图/脑电图 |
| `medical_illustration` | 医学图解 |

---

### 2.3 Tier 3：医学术语密度检测（核心防线）

**核心思想**：真实的医学影像在结构化分析中会产生大量解剖/病理术语（15-30个），而非医学图片几乎不会包含这些词汇（0-2个）。这个检测不依赖 LLM 判断，完全基于可量化的术语匹配。

**医学术语词库**（`_MEDICAL_ANATOMY_TERMS`，80+ 术语）：

```
# 中文解剖/病理术语
脑实质、脑室、脑沟、脑回、脑干、小脑、大脑、灰质、白质、
基底节、丘脑、内囊、外囊、额叶、颞叶、顶叶、枕叶、岛叶、
中线、占位、水肿、血肿、缺血、低密度、高密度、
DWI、ADC、FLAIR、T1、T2、SWI、GRE、
血管、动脉、静脉、狭窄、闭塞、灌注、
出血、梗死、钙化、软化、萎缩、扩张、
信号、密度、增强、强化、病变、异常、
左侧、右侧、双侧、对称、不对称、供血区、

# 英文术语
brain、cerebral、cerebellar、ventricle、sulci、gyrus、cortex、
white matter、gray matter、basal ganglia、thalamus、

# 检验/临床术语
血小板、凝血、INR、PT、APTT、纤维蛋白原、血糖、血脂、
房颤、窦性心律、ST段、T波、QT间期、

# 报告/病理术语
影像所见、诊断意见、切片、染色、HE、免疫组化、
```

**脑卒中关键词**（`_STROKE_KEYWORDS`，27 个）：

```
脑卒中、中风、卒中、脑梗、脑梗死、脑出血、脑缺血、
脑血管、缺血性、出血性、梗死、梗塞、血栓、
大脑中动脉、大脑前动脉、大脑后动脉、基底动脉、颈内动脉、
溶栓、取栓、抗血小板、抗凝、
stroke、cerebral、infarction、hemorrhage、ischemic、
颅内、脑实质、脑室、脑沟、蛛网膜下腔
```

**非医学指标黑名单**（`_NON_MEDICAL_INDICATORS`，60+ 条目）：

```
数学、数学题、方程式、代数、几何、微积分、考试题、试卷、
自拍、大头照、证件照、肖像、人像、合影、portrait、selfie、
猫、狗、宠物、食物、餐厅、汽车、风景、旅游、运动、游戏、
手机、截图、聊天、表格、excel、word、ppt、合同、发票、
胸部、骨折、牙科、眼科、孕妇、儿科、
this is a photo of、everyday scene、casual、snapshot、
```

**判断规则**：

| 条件 | 结果 | 说明 |
|------|------|------|
| 医学术语 ≥ 5 | ✅ 放行 | 真实医学影像的典型特征 |
| 卒中关键词 ≥ 3 且 术语 ≥ 2 | ✅ 放行 | 明确卒中内容 |
| 潜在医学类型 + 术语 ≥ 3 + 置信度 > 0.3 | ✅ 放行 | 心电图/检验报告等 |
| courseware_image + 卒中≥2 + 术语≥3 + 置信度>0.4 | ✅ 放行 | 课件资料需严格条件 |
| **其他所有情况** | 🚫 拦截 | 默认不信任 |

## 4. 拒绝提示

被拦截时，用户会收到明确的友好提示：

```
⚠️ 图片已被拦截

经 AI 医学影像门控系统检测，您上传的图片与脑卒中（中风）医学内容无关。

本系统仅支持脑卒中相关的医学影像分析，包括但不限于：
- 🧠 头部CT / MRI — 脑梗死、脑出血的影像判读
- 🔬 脑血管造影（CTA/MRA/DSA）— 血管狭窄、闭塞、动脉瘤
- 🩻 病理切片 — 脑卒中相关组织学
- 📊 心电图 — 房颤等心源性卒中风险评估
- 📋 检验报告 / 影像报告 — 脑卒中相关实验室检查

请上传与脑卒中相关的医学影像。如需其他帮助，请用文字描述您的学习需求。
```

## 7. 设计原则

1. **默认不信任**：任何图片默认被视为非医学，直到提供充分证据
2. **硬指标优先**：依赖可量化的术语匹配，而非 LLM 的文本判断
3. **多层冗余**：三层防护互为补充，单层失败不影响整体
4. **友好拒绝**：拦截时给出明确的理由和替代建议
5. **性能优先**：Tier 1 快速门控在最外层，避免对非医学图片做昂贵的结构化分析
