### 3.2 退火校验算法（条件覆盖）

```
被测函数: ValidateWithAnnealing(proposal, agents, reflection_count, decay_factor, min_weight)
源文件: model/agents/validate_node.py

测试条件:
  C1: proposal 通过校验 (validation_result == "pass")
  C2: proposal 未通过 AND reflection_count < max_reflections
  C3: proposal 未通过 AND reflection_count >= max_reflections

每个条件内部:
  C1.1: 不衰减权重, 不修改 agent_weights
  C2.1: decay_factor * weight > min_weight -> 衰减到 decay_factor * weight
  C2.2: decay_factor * weight <= min_weight -> 设为 min_weight
  C3.1: 返回失败, 停止重试
```

| 用例ID | 条件 | 覆盖率 | 测试数据 | 预期结果 | 结果 |
|:---|:---|:---:|:---|:---|:---:|
| WB-VAL-01 | C1.1 | 100% | 高质量proposal | pass, 权重不变 | ✅ |
| WB-VAL-02 | C2.1 | 100% | 中质量+weight=1.0 | fail, weight=0.7 | ✅ |
| WB-VAL-03 | C2.2 | 100% | 低质量+weight=0.25 | fail, weight=0.2 | ✅ |
| WB-VAL-04 | C3.1 | 100% | 3次失败 | 停止重试 | ✅ |
