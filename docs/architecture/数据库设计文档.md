# 多智能体个性化学习系统 — 数据库设计文档

> **版本**：V1.0  
> **项目名称**：LearnAgent — 基于大模型的个性化资源生成与学习多智能体系统  
> **数据库**：MySQL 8.0（兼容 5.7）  
> **字符集**：utf8mb4  
> **编制日期**：2026-06-29  

---

## 1. 引言

### 1.1 编写目的

本文档对系统数据库的表结构设计、字段定义、索引策略、外键约束、ER 关系进行完整描述，作为数据库开发、维护和数据迁移的基准文档。

### 1.2 数据库概述

- **数据库名**：medai
- **引擎**：InnoDB（支持事务、行锁、外键）
- **字符集**：utf8mb4（支持中文和 Emoji）
- **排序规则**：utf8mb4_general_ci
- **时间字段**：统一使用 DATETIME，默认 CURRENT_TIMESTAMP，更新时 ON UPDATE CURRENT_TIMESTAMP
- **主键策略**：BIGINT UNSIGNED AUTO_INCREMENT
- **软删除**：未采用，使用外键 ON DELETE CASCADE 级联删除

## 3. 数据表详细设计

### 3.1 user — 用户表

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键ID |
| name | VARCHAR(32) | NOT NULL, UNIQUE | — | 用户名 |
| password | VARCHAR(255) | NOT NULL | — | 密码（BCrypt哈希） |
| image | VARCHAR(255) | NULL | NULL | 头像URL |
| major | VARCHAR(64) | NULL | NULL | 专业 |
| grade | VARCHAR(16) | NULL | NULL | 年级 |
| specialty | VARCHAR(64) | NULL | NULL | 专长 |
| create_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**：

| 索引名 | 类型 | 字段 | 说明 |
|:---|:---|:---|:---|
| PRIMARY | 主键 | id | 聚簇索引 |
| name | 唯一索引 | name | 用户名唯一性约束 |

**设计说明**：
- password 存储 BCrypt 哈希值，不可逆加密
- major/grade/specialty 为后期 ALTER 新增字段，支持学生画像构建
- image 默认为 `/images/default.png`

---

### 3.2 talk — 对话表

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| id | BIGINT UNSIGNED | PK | — | 对话ID（时间戳生成） |
| user_id | BIGINT UNSIGNED | NOT NULL, FK | — | 用户ID |
| title | TEXT | NOT NULL | — | 对话标题 |
| content | LONGTEXT | NOT NULL | — | 对话摘要内容 |
| create_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**：

| 索引名 | 类型 | 字段 | 说明 |
|:---|:---|:---|:---|
| PRIMARY | 主键 | id | 时间戳作为主键，天然有序 |
| idx_user_id | 普通索引 | user_id | 按用户查询对话列表 |

**外键**：

| 约束名 | 字段 | 引用 | 删除策略 |
|:---|:---|:---|:---|
| fk_talk_user | user_id | user(id) | CASCADE |

**设计说明**：
- id 使用时间戳生成（非自增），保证分布式环境下的唯一性
- content 存储对话摘要，完整消息内容存储在 cont 表

---

### 3.3 cont — 消息内容表

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键ID |
| user_id | BIGINT UNSIGNED | NOT NULL | — | 用户ID |
| talk_id | BIGINT UNSIGNED | NOT NULL, FK | — | 对话ID |
| content | LONGTEXT | NOT NULL | — | 消息内容 |
| role | VARCHAR(16) | NOT NULL | 'user' | 角色：user/assistant |
| images | TEXT | NULL | NULL | 图片附件（Base64 JSON数组） |
| create_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引**：

| 索引名 | 类型 | 字段 | 说明 |
|:---|:---|:---|:---|
| PRIMARY | 主键 | id | — |
| idx_talk_id | 普通索引 | talk_id | 按对话查询消息列表 |

**外键**：

| 约束名 | 字段 | 引用 | 删除策略 |
|:---|:---|:---|:---|
| fk_cont_talk | talk_id | talk(id) | CASCADE |

**设计说明**：
- role 字段区分用户消息和 AI 回复，通过 ROW_NUMBER 窗口函数对历史数据做了回填修正
- images 字段仅 user 消息有值，存储 Base64 编码的图片列表（JSON数组）
- 一问一答交替写入，奇数位为用户消息，偶数位为 AI 回复

| order_index | INT | NOT NULL | — | 步骤顺序 |

| description | TEXT | NULL | NULL | 步骤描述 |

| difficulty | VARCHAR(16) | NULL | NULL | 难度 |
| status | VARCHAR(16) | NOT NULL | 'not_started' | 状态 |
| actual_hours | DECIMAL(5,1) | NULL | NULL | 实际耗时 |
| feedback | TEXT | NULL | NULL | 学习反馈 |
| self_rating | TINYINT | NULL | NULL | 自我评分1-5 |
| prerequisites | JSON | NULL | NULL | 前置步骤ID列表 |
| create_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**status 枚举值**：

| 值 | 说明 |
|:---|:---|
| not_started | 未开始 |
| in_progress | 进行中 |
| completed | 已完成 |
| skipped | 已跳过 |

**索引**：

| 索引名 | 类型 | 字段 | 说明 |
|:---|:---|:---|:---|
| PRIMARY | 主键 | id | — |
| idx_path_id | 普通索引 | path_id | 按路径查询步骤 |
| idx_order | 复合索引 | (path_id, order_index) | 按路径+顺序排序 |

**外键**：

| 约束名 | 字段 | 引用 | 删除策略 |
|:---|:---|:---|:---|
| fk_step_path | path_id | learning_path(id) | CASCADE |

**设计说明**：
- prerequisites 存储前置步骤的 ID 列表（JSON数组），支持 DAG 依赖关系
- order_index 保证步骤的线性展示顺序

### 3.8 step_resource — 步骤资源关联表

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|:---|:---|:---|:---|:---|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | — | 主键ID |
| step_id | BIGINT UNSIGNED | NOT NULL, FK | — | 步骤ID |
| resource_id | BIGINT UNSIGNED | NOT NULL, FK | — | 资源ID |
| relevance | DECIMAL(3,2) | NULL | NULL | 相关度评分0-1 |
| is_recommended | TINYINT | NOT NULL | 0 | 是否为推荐资源 |
| create_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引**：

| 索引名 | 类型 | 字段 | 说明 |
|:---|:---|:---|:---|
| PRIMARY | 主键 | id | — |
| idx_step_id | 普通索引 | step_id | 按步骤查询资源 |
| idx_resource_id | 普通索引 | resource_id | 按资源查询步骤 |

**外键**：

| 约束名 | 字段 | 引用 | 删除策略 |
|:---|:---|:---|:---|
| fk_step_resource_step | step_id | learning_path_step(id) | CASCADE |
| fk_step_resource_resource | resource_id | learning_resource(id) | CASCADE |

**设计说明**：
- 典型的多对多关联表，支持一个步骤关联多个资源，一个资源被多个步骤引用
- relevance 字段存储 AI 计算的相关度评分，用于排序展示
- is_recommended 标记 AI 重点推荐的资源

## 5. 索引设计策略

### 5.1 索引设计原则

1. **主键索引**：所有表使用 BIGINT UNSIGNED AUTO_INCREMENT 作为聚簇索引
2. **外键索引**：所有外键字段自动创建普通索引，加速 JOIN 查询
3. **查询索引**：根据业务查询模式创建复合索引（如 learning_path_step 的 path_id + order_index）
4. **唯一索引**：user.name、student_profile.user_id 等需要唯一性约束的字段

### 5.2 索引统计

| 表名 | 索引数量 | 说明 |
|:---|:---|:---|
| user | 2 | PK + name唯一 |
| talk | 2 | PK + user_id |
| cont | 2 | PK + talk_id |
| student_profile | 2 | PK + user_id唯一 |
| learning_resource | 4 | PK + user_id + type + course_name |
| learning_path | 3 | PK + user_id + status |
| learning_path_step | 3 | PK + path_id + (path_id, order_index) |
| step_resource | 3 | PK + step_id + resource_id |
| learning_behavior | 4 | PK + user_id + behavior_type + create_time |
| evaluation_report | 3 | PK + user_id + path_id |

## 6. 数据迁移说明

### 6.1 初始化脚本

- **完整建库脚本**：`learningo-agents.sql`（包含建表+示例数据）
- **增量脚本**：`schema_additions.sql`（新增表和字段 ALTER）

### 6.2 执行顺序

1. 创建 medai 数据库
2. 执行 `learningo-agents.sql`（创建所有表并插入基础数据）
3. 如需从旧版升级，执行 `schema_additions.sql`（ALTER 添加新字段和新表）

### 6.3 注意事项

- `learningo-agents.sql` 使用 `DROP TABLE IF EXISTS`，会清除现有数据
- `schema_additions.sql` 中的 cont 表 role 字段回填使用了窗口函数，需 MySQL 8.0+
- 所有外键约束使用 ON DELETE CASCADE，删除父记录会级联删除子记录
- JSON 字段需要 MySQL 5.7.8+ 版本支持
