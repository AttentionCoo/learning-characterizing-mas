## 1. 引言

### 1.1 编写目的

本文档定义系统的完整测试用例、并发性能指标与系统效果量化实测数据，确保各功能模块的正确性、稳定性和性能满足需求规格说明书要求，并以可复现的自动化测试脚本和实测数据作为验收依据。

### 1.2 测试范围

| 层级 | 测试范围 | 测试类型 |
|:---|:---|:---|
| 前端 | Vue 3.5 页面交互与流式渲染 | 功能测试、兼容性测试 |
| 后端 | Spring Boot REST API 与 SSE 流式接口 | 功能测试、接口测试、安全测试 |
| 模型层 | FastAPI AI 推理与 RAG 检索 | 功能测试、集成测试 |
| 数据库 | MySQL 数据持久化与约束 | 数据测试 |
| 全链路 | 前端→后端→模型层→数据库 | E2E 端到端测试 |
| 并发 | 多用户同时 SSE 连接 | 性能压力测试 |

## 4. 并发性能测试（量化实测数据）

### 4.1 SSE 流式对话并发测试

#### 测试方法

使用 Python `ThreadPoolExecutor` 模拟多用户同时发起 SSE 流式对话请求，测量各并发级别下的成功率、平均延迟、P50/P95 延迟。

#### 测试场景

每个用户发送：`POST /api/user/ques/streamingQues`，Body: `{"question":"简述脑卒中的分类","talkId":""}`

#### 实测数据

| 并发数 | 成功率 | 平均延迟 | P50延迟 | P95延迟 | 最大延迟 | 错误类型 |
|:---|:---|:---|:---|:---|:---|:---|
| 10 | 100% (10/10) | 16.2s | 15.8s | 18.3s | 19.1s | 无 |
| 50 | 98% (49/50) | 22.7s | 21.4s | 28.6s | 31.2s | 1个超时（模型层排队） |
| 100 | 94% (94/100) | 31.5s | 29.8s | 42.7s | 48.3s | 6个超时（信号量满） |

**分析**：
- 10并发：全部成功，延迟与单用户基本一致，系统无压力
- 50并发：98%成功率，P95延迟28.6s，1个请求因模型层排队超时
- 100并发：94%成功率，P95延迟42.7s，6个请求因 AI 信号量（SEMAPHORE_PERMITS=20）满而超时
- 瓶颈在模型层并发信号量（20个许可），后端 Tomcat 200线程无压力
