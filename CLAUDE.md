## Agent skills

### Issue tracker

Issues live in GitHub Issues via the `gh` CLI. PRs are not treated as a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default canonical label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` at the repo root, plus `docs/adr/`. See `docs/agents/domain.md`.
